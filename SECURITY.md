# Security reporting

Please use GitHub's **Report a vulnerability** feature on this repository's Security tab. Do not disclose exploitable details, credentials or personal financial data in public issues. If private reporting is temporarily unavailable, open a public issue that only asks for a private reporting channel, without sensitive details.

Include affected version, Windows version, a synthetic reproduction and the expected/actual behavior. Never attach a real ledger, full backup, bank statement, token, password or signing key. Redact screenshots and logs.

Only the latest published version is actively maintained. Local files are not an encrypted vault; protect the Windows account and independent backups. The installer is unsigned until a trusted signing identity is available.
