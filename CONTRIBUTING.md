# Contributing

Open an issue before a large change. Use small descriptive commits and preserve accounting invariants, audit history, recovery checks and source compatibility. Run npm run typecheck, npm test and the desktop smoke suites in docs/BUILDING.md.

Use only synthetic financial data and fictitious identities. Never commit ledgers, backups, secrets, private migration mappings or screenshots containing real data. Dependencies and generated binaries do not belong in source history.

Security reports go through SECURITY.md. Contributions are submitted under the repository's MIT license.
